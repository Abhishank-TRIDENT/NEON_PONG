HOW TO PLAY

A clean rule set. A demanding opponent. Keep your eyes on the ball and use the paddle impact point to control your return angle.

01 — MOVE

Use ↑ / ↓ or W / S to move your cyan paddle. Hold a key for smooth movement.

02 — AIM YOUR SHOT

Hit near the paddle centre for a straighter return. Hit near the top or bottom edge to send sharper angled shots.

03 — OUTPLAY THE CPU

Change your shot angles. The CPU reacts with a delay and has limited movement speed—make it cover more court.

04 — WIN THE MATCH

First to 7 points wins. The ball accelerates after paddle hits, so rallies get intense.

CREATOR PROFILE // SYSTEM BLUEPRINT

THE MIND BEHIND THE MACHINE.

ABHISHANK — CREATOR · DEVELOPER · GAME ARCHITECT
One developer. One file. One entire arcade arena.
Abhishank brings a builder's curiosity and an engineer's instinct to the screen. He doesn't just want a game that runs—he wants every collision to feel deliberate, every animation to feel alive, and every rally to tell a story. A sharp-minded creator, a relentless experimenter, and the human who decided the CPU should actually put up a fight. The arena carries his signature.

This is an original, self-contained browser game made by Abhishank. Its architecture is deliberately lightweight: no third-party game engine, no external packages, no downloaded sound assets.

01 // PRESENTATIONHTML5 + CSS3

Menu, HUD, score display, responsive layout, neon styling, overlays and transitions.

02 // RENDERINGHTML5 Canvas 2D

Draws the arena, paddles, ball, trail, glow, grid and impact particles frame by frame.

03 // GAME COREVanilla JavaScript

Owns the match state, keyboard input, delta-time animation loop, collisions, scoring and ball physics.

04 // CPU CONTROLLERHeuristic AI

Uses periodic estimates, reaction delay, aiming uncertainty and a capped movement speed to stay challenging but beatable.

05 // AUDIO ENGINEWeb Audio API

Generates synth-style music and sound effects in real time using oscillators and gain envelopes—no audio files needed.

06 // DELIVERYSingle-file architecture

All HTML, CSS and JavaScript live together. Open locally in a modern browser; no server or installation required.

Developer's note: The code is the blueprint; the feel of the game is the craft. Built, tuned and brought to life by Abhishank.
